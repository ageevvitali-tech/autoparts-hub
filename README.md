# HAB-2026 / AutoParts Hub

Сильная стартовая версия проекта: интерфейс поиска, сегменты транспорта, каталог, заявки на сервер, AI-помощник, админ-демо, аналитика, PostgreSQL-схема и защищённая архитектурная основа.

## Запуск

Требуется Node.js 20+.

```bash
npm start
```

Открыть:

```text
http://localhost:10000
```

Проверка:

```text
http://localhost:10000/api/health
```

Проверка синтаксиса:

```bash
npm run check
```

Smoke test:

```bash
npm run smoke
```

## Что уже есть

- адаптивный интерфейс;
- фотография в hero и карточках;
- поиск по номеру/названию/бренду/технике;
- сегменты: легковые, LCV, грузовые, автобусы, мото, прицепы, спецтехника;
- карточка товара;
- заявка на сервер;
- локальный AI-помощник с готовым API-контуром для настоящего провайдера;
- админ-демо;
- lost demand / zero-result analytics;
- PostgreSQL production schema;
- audit log model;
- supplier offers model;
- Telegram integration point without secrets in frontend.

## Что сознательно не выдаётся за готовое

- реальные миллионы товаров;
- реальные остатки и цены поставщиков;
- подтверждённый VIN-подбор;
- реальный Telegram Bot API;
- настоящая AI vision/OCR интеграция;
- онлайн-платежи;
- production auth.

Сначала подключаются источники данных и безопасность, затем масштабирование.

## Конкурентные принципы

Изученные паттерны рынка: поиск по VIN/артикулу/названию, каталоги заменителей, варианты поставки, цены и сроки, помощь специалистов, каталоги для разных типов техники. AutoParts Hub должен не копировать интерфейс конкурентов, а соединить сильные практики с собственным акцентом: единый запрос, подтверждение применяемости, zero-result intelligence, AI-помощник и мультисегментность.
