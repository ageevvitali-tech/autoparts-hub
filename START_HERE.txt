HAB-2026 v0.9.2 RENDER-SAFE

Главное изменение: критический CSS и JS встроены в public/index.html, поэтому страница не становится голым HTML даже если Render отдаёт статические файлы без app.css/app.js. Все сцены используют локальные /assets/... без Unsplash. WebP MIME добавлен в server.js.

Локальный запуск:
npm install
npm start
http://localhost:10000

Для Render Web Service: Build Command = npm install; Start Command = npm start.
