Что делает Hub умнее обычного магазина

Берём лучшие пользовательские сценарии рынка, но строим собственную систему.

🔎

Поиск без угадывания

Артикул, OEM/OE, название, VIN, марка/модель/год/двигатель и естественное описание проблемы. Нормализация, опечатки и варианты написания закладываются в API.

🧠

ИИ-помощник

Фото детали, нечитаемый номер, описание неисправности, подбор аналогов и сопутствующих товаров. ИИ предлагает кандидатов, но не подменяет подтверждённые данные каталога.

🛡️

Проверяемость

Для каждой детали предусматриваем источник, применимость, OE/OEM, аналоги, поставщика, цену, наличие и срок. Неподтверждённые догадки не выдаём за факт.

📦

Мультипоставщик

Архитектура позволяет объединять предложения поставщиков и сравнивать цену, остаток, срок и условия доставки.

📈

Поиск становится аналитикой

Записываем запросы, нулевые результаты, клики, переходы в заявку и повторные поиски. Это база для расширения ассортимента.

🤖

Telegram + CRM

Заявка получает ID и может пройти путь: новая → уточнение → подбор → предложение → заказ → отгрузка → завершено. Токены бота никогда не лежат в браузере.

AI ASSISTANT

Помощник, который понимает задачу

Пользователь сможет написать обычными словами: «нужны передние колодки на Camry 70, 2.5, 2019». Система извлечёт сущности, уточнит критичные параметры и покажет подтверждённые варианты.

ДОВЕРИЕ

Не просто «дёшево», а понятно

✓ Оригинал / аналог
Ясно, что именно предлагается.
✓ Применимость
Связь детали с автомобилем и источником.
✓ Цена + наличие + срок
Сравнение поставок вместо одной цены.
✓ Запрос, если не нашли
Нулевой поиск превращается в потенциальную продажу.

Защита закладывается с первого дня

Это UI-уровень будущей системы безопасности; реальные проверки выполняются сервером.

🔐 Секреты

API-ключи, Telegram Bot Token и DATABASE_URL не хранятся в index.html.

🧱 Серверная валидация

Frontend не считается доверенной средой. Все критичные операции повторно проверяются API.

🚦 Rate Limit

Ограничение частоты запросов и защита публичных API от злоупотреблений.

👤 Роли

Клиент, менеджер, администратор и отдельные права на критичные действия.

📝 Audit Log

Логирование изменений каталога, заказов, прав и важных административных действий.

💾 Backup

Резервное копирование БД и проверка восстановления, а не просто наличие архивов.
